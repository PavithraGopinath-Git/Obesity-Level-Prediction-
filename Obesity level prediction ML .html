Building a Machine Learning Pipeline for Predicting Obesity Levels from Lifestyle and Demographic Factors"¶

1. Business Problem:¶

The objective of this work is to find the obesity level of a person based on demographic, dietetic, physical activity, and lifestyle parameters. This is a multiclass classification problem, where the target variable NObeyesdad includes seven levels of obesity. The input variables include attributes like age, sex, height, weight, dieting, physical activities, and family history of overweight.

It is important to address this problem due to the significance of obesity as a public health problem related to chronic diseases and high costs of medical services.

2. Source of Data:¶

https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition

Reference - semanticscholar.org/paper/35b40bacd2ffa9370885b7a3004d88995fd1d011

Data in Brief¶

This dataset includes 2,111 records with 16 variables where NObeyesdad is the target variable. The features available in the data set include demographics, food, physical, and lifestyle. Features include Age, Gender, Height, Weight, Family History of Obesity, Hydration, Physical Activity, and Transportation mode. Target variable is related to classifying individuals on the basis of seven classes of obesity starting from underweight to obesity Class III.

This data set has been manually downloaded from UCI data sets and has been loaded in Jupyter notebook using pandas library.

Observation¶

Feature scaling is introduced in Strategy B to ensure that numerical variables such as age, weight, and height contribute equally to distance-based or gradient-based models. To prepare the dataset for modeling, these variables were changed into binary numerical feature through 1 hot encoding.

Result:¶

Model A employs simple preprocessing without any scaling of the features, whereas Model B scales the features using standardization. This scaling of the features will help ensure that all the numeric variables have an equal influence on the model since those with larger values can overwhelm the smaller ones.

from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder
from sklearn.linear_model import LogisticRegression

numeric_transformer = Pipeline(steps=[
    ("imputer", SimpleImputer(strategy="median"))
])

categorical_transformer = Pipeline(steps=[
    ("imputer", SimpleImputer(strategy="most_frequent")),
    ("encoder", OneHotEncoder(handle_unknown="ignore"))
])

preprocessor_A = ColumnTransformer([
    ("num", numeric_transformer, numeric_features),
    ("cat", categorical_transformer, categorical_features)
])

model_A = Pipeline(steps=[
    ("preprocessor", preprocessor_A),
    ("model", LogisticRegression(max_iter=5000,solver="saga"))
])

9.Machine Learning Models¶

Logistic Regression¶

1.It computes the probability of membership of an individual into different classes of obesity, depending on various features, including age, weight, height, eating behavior, and physical activity.

2.It is a basic and interpretable approach to find the solution of classifying obesity problem. Moreover, it gives the ability to estimate how separable the classes of obesity are given the features available.

3.Firstly, logistic regression implies relatively linear dependencies among the features and the target variable. Obesity, however, depends on complicated interactions between different lifestyle variables.

Random Forest classifier¶

1.This algorithm is a collection of classifier that takes into account the outcomes of classification of several decision trees developed on distinct divisions of training set.

2.In obesity dataset, we have both demographic and lifestyle variables. There may exist some complex and non-linear relations between them that the Random Forest model will be able to discover.

3.Though the Random Forest algorithm usually provides good results, the main drawback it has when compared to logistic regression is that it is less interpretable.

10. Tuning¶

Tuning was conducted to obtain the most suitable combination of parameter values. GridSearchCV with 5 fold cross-validation technique was uapplied for the assessment of different hyperparameter settings for Logistic Regression and Random Forest.

LR Hyperparameters¶

  • C: C: Controls regularization strength (low = stronger regularization, high = weaker).
  • Solver: employed to instruct the model

RF Hyperparameters¶

  • The forest size which improves robustness and accuracy as it increase
  • Higher depth can lead to overfitting
  • Minimum samples helps control overfitting when increased

Results of Hyperparameters Tuning¶

For Logistic Regression, the best hyperparameters are C = 10 and solver = lbfgs. The model demonstrated 93.71% cross-validation accuracy indicating a good and robust model.

For Random Forest, the set of the optimal hyperparameters includes 300 trees, max_depth parameter not being defined, and min_samples_split = 2. In this case, the cross-validation accuracy is 93.47% and is very close to the previous case.

However, it is necessary to note that both models showed high results in the process of hyperparameters tuning. Nevertheless, Logistic Regression was slightly better than Random Forest with regard to cross-validation accuracy and became the chosen model.

13. Conclusion¶

We designed a full end to end ML pipeline to estimate the obesity status respect to lifestyle and demographics factors. After EDA and data preprocessing (encoding, scaling, and imputation), both models were developed and optimized by means of GridSearchCV. Logistic Regression model achieved good results in terms of 93.71% cross-validation accuracy, and it was considered as the optimal model due to performance and interpretation aspects. Both models provided about 94% accuracy for the test data set.

Significant features turned out to be weight, height, eating, physical activity, and family history. The model can be used to find people who are at risk of having an obesity problem. The limitations of the present analysis include the representativeness of the dataset, and future improvements can be made by using more comprehensive datasets and better feature engineering.
